# api-db

API Node.js/Express backed by Microsoft SQL Server.

## Configuration

Copy `.env.example` to `.env` and provide the database values for your local or deployed environment. Do not commit `.env` or credentials to Git.

```text
DB_USER=your_database_user
DB_PASSWORD=your_database_password
DB_SERVER=your_database_server
DB_NAME=your_database_name
```
